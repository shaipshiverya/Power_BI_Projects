## 📌 Project Overview
An interactive Power BI dashboard analyzing 
Blinkit's grocery sales performance across 
multiple outlet types, sizes, and locations 
across India.

> 🟡 *"India's Last Minute App"*

## 📈 Dashboard Highlights

**Fat Content Analysis**
- Low Fat: 35.4% (425.3K)
- Regular: 64.6% (776.32K)

**Top Item Types by Sales**
- Fruits & Snacks — $0.18M each
- Household & Frozen — $0.14M
- Dairy & Canned — $0.10M

**Outlet Performance**
- Tier 3 outlets lead with **$472.13K** in sales
- Tier 2: $393.15K
- Tier 1: $336.40K

**Outlet Size**
- Medium outlets: 42.3%
- Small outlets: 37.01%
- High outlets: 20.7%

**Outlet Establishment Trend**
- Sales peak observed around **2018**
- Consistent growth from 2012–2022
